# Final Card Gate Checklist

Before publishing the final EchoIQ card, confirm every BET/LOTTERY has:

- [ ] Label
- [ ] Market type
- [ ] Player/team
- [ ] Game
- [ ] Current odds
- [ ] Implied probability
- [ ] Fair probability
- [ ] Edge
- [ ] Stake units
- [ ] Source confidence A/B
- [ ] Required gates passed
- [ ] Kill switch
- [ ] Short rationale
- [ ] Timestamp

If any item is missing, downgrade to LEAN/WATCHLIST/PASS.
