# EchoIQ v3 Quick Daily Run Prompt

Run EchoIQ v3 for today's MLB slate.

Produce:

1. Official starters/lineups/weather/odds status
2. Top HR candidates
3. Top TB/hit candidates
4. Top game side/total candidates
5. Verification board
6. Official BET card only if gates pass
7. LOTTERY card only if capped and justified
8. Watchlist
9. Pass/avoid list
10. Kill switches

Rules:

- Separate EXTERNAL from EchoIQ.
- No verified odds + fair probability + gate status = no bet.
- Keep the final card narrow.
- Do not force picks.
