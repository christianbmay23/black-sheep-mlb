# EchoIQ v3 Definition of Done

A daily slate is complete only when all of the following exist or are explicitly marked unavailable:

## Pregame

- Raw research board
- External/public predictions board
- Weather/park board
- Pitcher vulnerability board
- Candidate board
- Verification board
- Official card
- Watchlist
- Pass/avoid list
- Source confidence status

## Final card

Every official play must include:

- Label
- Market
- Odds
- Implied probability
- Fair probability
- Edge
- Stake
- Source confidence
- Gates passed
- Kill switch
- Short rationale

## Postgame

- Official card grade
- Conditional card grade
- Lottery grade
- Watchlist process grade
- External-source grade
- Source-compliance ledger
- Error ledger
- Model lessons
- Next-slate fixes
