Black Sheep MLB — Daily Date-Driven Export Workflow

1) Create the day-specific canvas file
   - File pattern: canvases/mlb-pregame-intel-<slug>.canvas.tsx
   - Example: canvases/mlb-pregame-intel-apr16.canvas.tsx

2) Update the two export marker sections in that canvas
   - <!-- games-csv:start --> ... <!-- games-csv:end -->
   - <!-- batter-outlooks-csv:start --> ... <!-- batter-outlooks-csv:end -->

3) Generate exports for the slate
   - python canvases/exports/build_ml_exports.py --date 2026-04-16
   - or: python canvases/exports/build_ml_exports.py --date apr16

3b) Apr 16 only — refresh CSV marker blocks from MLB API (keeps dashboard UI)
   - python3 canvases/exports/_gen_apr16_canvas.py
   - (splices games-csv + batter-outlooks-csv; runs build_ml_exports for 2026-04-16)

4) Minimal workflow for a new slate
   - Copy prior day canvas to new slug
   - Refresh only games-csv and batter-outlooks-csv blocks
   - Run export command
   - Verify three outputs in canvases/exports/

5) Backward compatibility
   - Running python canvases/exports/build_ml_exports.py with no --date still defaults to apr15
