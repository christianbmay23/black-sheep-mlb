# EchoIQ v3 Slate Template

Copy this folder to `slates/<YYYY-MM-DD>/` when a real slate is requested.

## Folder Map

- `00_inputs/`: user-provided instructions, date scope, manual odds, and source notes.
- `01_raw_research/`: raw GPT/Deep Research exports and public prediction pulls.
- `02_candidates/`: normalized candidates and external public predictions.
- `03_verification/`: verification board, source compliance, weather, park, pitcher, and lineup boards.
- `04_final_card/`: official card, lottery card, conditional card, watchlist, pass/avoid, and final report.
- `05_postgame/`: postgame grade, postgame report, error ledger, and model lessons.
- `06_archive/`: stale, superseded, or pre-verification artifacts.

Use `echoiq_v3/templates/` as the source for CSV and report templates.
