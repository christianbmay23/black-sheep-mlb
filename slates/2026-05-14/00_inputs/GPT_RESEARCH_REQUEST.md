# GPT/Deep Research Request - EchoIQ v3 Slate

Date: 2026-05-14

Prepare a verified research packet for the EchoIQ v3 semi-manual dry run. Do not promote official bets. Provide source links and timestamps for every current-data claim.

## Required Outputs

1. Slate map
   - Every MLB game on the slate
   - Start time
   - Venue
   - Game status at research time

2. Confirmed/probable starters
   - Away starter
   - Home starter
   - Starter confidence
   - Opener/bulk-role notes where relevant

3. Lineup status
   - Confirmed, projected, unavailable, or conflicting
   - Source for each lineup status
   - Key batting-order notes

4. Injuries/scratches
   - Player
   - Team
   - Status
   - Impact on matchup or market

5. Odds snapshot
   - Sportsbook/source
   - Timestamp
   - Moneyline
   - Total
   - Run line where available
   - Player prop prices where available

6. Weather/park board
   - Temperature
   - Wind speed and direction
   - Precipitation or roof status
   - Park factors or Ballpark Pal-style context if available

7. HR candidates
   - Player
   - Team
   - Opposing pitcher
   - Lineup spot/status
   - Current HR price if verified
   - Supporting factors
   - Risk flags

8. TB/hit candidates
   - Player
   - Team
   - Opposing pitcher
   - Market line and price if verified
   - Supporting factors
   - Risk flags

9. Game side/total candidates
   - Game
   - Side or total
   - Current price
   - Fair-probability rationale if available
   - Risk flags

10. Source confidence table
    - Source
    - Data type
    - Timestamp
    - Confidence grade
    - Notes

11. Missing data list
    - Missing field
    - Affected game/player
    - Impact
    - Recommended label cap

## Label Boundary

Use `WATCHLIST`, `LEAN`, or `CONDITIONAL` only until odds, lineups, starters, weather, source confidence, fair probability, edge, and kill switches are verified. Do not recommend `BET` rows without the full gate package.
